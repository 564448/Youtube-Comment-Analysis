# YouTube Comment Analysis

ระบบดึงและวิเคราะห์ความคิดเห็น (Comments) จาก YouTube อัตโนมัติ โดยใช้พลังของปัญญาประดิษฐ์ในท้องถิ่น (**Local LLM**) ผ่าน **Ollama** เพื่อจัดกลุ่มเนื้อหา สรุปอารมณ์ และประเด็นสำคัญภาษาไทยได้อย่างแม่นยำ รองรับการใช้งานทั้งในรูปแบบคำสั่ง (**CLI**) และหน้าต่างเว็บ (**WebUI**) ที่ใช้งานง่าย

---

## คุณสมบัติเด่น (Features)

* **Dual-Mode Interface:** เลือกใช้งานได้ตามความถนัด ทั้งรูปแบบ **CLI** (Command Line) สำหรับสาย Dev และ **WebUI** สำหรับผู้ใช้งานทั่วไป
* **Robust YouTube Scraper:** รองรับ URL ทุกรูปแบบ (วิดีโอปกติ, Shorts, Short Link) สามารถดึงคอมเมนต์หลักรวมถึงคอมเมนต์ตอบกลับ (Replies) ได้อย่างครบถ้วน พร้อมระบบ Data Cleaning ลบค่าว่างอัตโนมัติ
* **Local AI Analysis:** วิเคราะห์ข้อมูลอย่างปลอดภัยในเครื่อง 100% ไม่ต้องเสียค่า API รายเดือน โดยใช้โมเดลภาษาไทยชั้นนำ (เช่น `Qwen 2.5` หรือ `Typhoon`) ผ่าน Ollama
* **Batch Processing:** แบ่งชุดข้อมูลส่งให้ AI ประมวลผลทีละ 25 คอมเมนต์ ช่วยควบคุมการใช้ VRAM (รองรับการทำงานบนการ์ดจอ VRAM 8GB ได้เป็นอย่างดี)
* **Smart Clustering & Summary:** จัดกลุ่มความคิดเห็นตามหัวข้อ (Category) แยกแยะอารมณ์ (ชื่นชม, ติเตียน, เสนอแนะ) และสรุปประเด็นหลักที่พูดซ้ำกันมากที่สุด
* **Excel Ready:** ส่งออกผลลัพธ์เป็นไฟล์ CSV ในรูปแบบ `utf-8-sig` ทำให้เปิดอ่านภาษาไทยบน Microsoft Excel ได้ทันทีโดยไม่เพี้ยน พร้อมคำนวณสัดส่วนเปอร์เซ็นต์ (%) ให้เสร็จสรรพ

---

## โครงสร้างและการทำงานของโปรแกรม (How it Works)

โปรแกรมจะทำงานประสานกันเป็น 5 ขั้นตอนหลัก ดังนี้:
1.  **ดึงข้อมูล (Fetch):** ดึงคอมเมนต์ทั้งหมดจาก YouTube API ตามลิงก์ที่ระบุ พร้อมตรวจสอบตรวจสอบความถูกต้องเทียบกับยอดรวมบนระบบ
2.  **เตรียมข้อมูล (Extract):** อ่านข้อมูลจากไฟล์ CSV และสกัดเฉพาะข้อความคอมเมนต์มาจัดลง List
3.  **ตั้งกฎเหล็ก (Prompting):** ใช้ System Prompt ควบคุมให้ AI ทำหน้าที่เป็น Data Analyst ตอบกลับเป็นโครงสร้าง JSON และใช้ภาษาไทยเท่านั้น
4.  **ประมวลผล (Analysis):** ส่งข้อมูลแบบ Batch ให้ Local LLM ทำการจัดกลุ่มและวิเคราะห์ทิศทางข้อความ
5.  **รวมผลและส่งออก (Aggregation & Export):** ใช้ Python รวบรวมกลุ่มที่ซ้ำกัน คำนวณเปอร์เซ็นต์ และบันทึกเป็นไฟล์รายงานสรุปผลลัพธ์ฉบับสมบูรณ์

## วิธีการใช้งาน (How to Use)

โปรแกรมนี้ออกแบบมาให้รองรับผู้ใช้ทุกระดับ โดยมีวิธีการเข้าใช้งาน 2 รูปแบบ:

### 1. สำหรับผู้ใช้งานทั่วไป (WebUI Mode) 
หากคุณไม่ต้องการพิมพ์คำสั่งใน Terminal คุณสามารถเปิดใช้งานหน้าต่างโปรแกรมบนเว็บเบราว์เซอร์ได้ง่าย ๆ:
* ดับเบิลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์โปรแกรม
* ระบบจะทำการรันสคริปต์ Streamlit และเปิดหน้าเว็บเบราว์เซอร์ให้คุณโดยอัตโนมัติ
* วางลิงก์ YouTube และกดปุ่มเริ่มวิเคราะห์ผ่านหน้าจอเพื่อดูตารางสรุปและกราฟสถิติได้ทันที

### 2. สำหรับนักพัฒนา / สายสั่งการ (CLI Mode) 
หากต้องการรันผ่าน Command Line Interface เพื่อความรวดเร็วหรือนำไปพ่วงต่อกับระบบอื่น:
* เปิด Terminal หรือ PowerShell ในโฟลเดอร์โครงการ
* รันคำสั่ง:
    ```bash
    python CLI.py
    ```
* ใส่ลิงก์ YouTube ตามที่โปรแกรมร้องขอ ระบบจะประมวลผลหลังบ้านและบันทึกไฟล์ผลลัพธ์ลงในโฟลเดอร์ทันที

## สิ่งที่ต้องเตรียมก่อนเริ่มใช้งาน (Prerequisites)

1.  **Python 3.10+** และติดตั้งไลบรารีที่จำเป็น (เช่น `pandas`, `streamlit`, `google-api-python-client`, `ollama`)
2.  **Ollama:** ติดตั้งโปรแกรม Ollama ในเครื่อง และดาวน์โหลดโมเดลที่ต้องการใช้งาน เช่น:
    ```bash
    ollama run qwen2.5:latest
    ```
3.  **YouTube API Key:** นำ API Key ที่ได้จาก Google Cloud Console มาใส่ไว้ในไฟล์ `API_Key.txt` เพื่อให้ระบบสามารถดึงคอมเมนต์ได้

## โครงสร้างโฟลเดอร์โครงการ (Project Structure)

* `CLI.py` — ไฟล์หลักสำหรับการรันโปรแกรมในรูปแบบ Command Line
* `Analytic.py` — โมดูลสมองกลสำหรับส่งคำสั่งแบ่งกลุ่มคอมเมนต์และคำนวณเปรียบเทียบใน Python
* `Analytic_For_WebUI.py` — โมดูลวิเคราะห์ข้อความที่ปรับปรุงโครงสร้างเพื่อรองรับ Queue สัญญาณความคืบหน้า (Progress Bar) บนเว็บ
* `Fetch.py` — สคริปต์เชื่อมต่อ YouTube API สกัดวิดีโอไอดี ดึงข้อมูลคอมเมนต์หลักและคอมเมนต์ย่อย
* `Extract.py` — ฟังก์ชันสำหรับเปิดอ่านไฟล์ข้อมูลดิบเพื่อแปลงไปเป็น List ส่งต่อให้ AI
* `get_api_key.py` — ฟังก์ชันสำหรับโหลดอ่าน Key จากไฟล์ภายนอกอย่างปลอดภัย
* `prompt.txt` — ไฟล์ควบคุมคำสั่งและบทบาท (System Prompt) ของ Data Analyst
* `API_Key.txt` — ไฟล์สำหรับจัดเก็บรหัสผ่านการเชื่อมต่อ YouTube API
* `start.bat` — ไฟล์ทางลัดสำหรับกดรันหน้าเว็บอินเตอร์เฟส (Streamlit) ได้ในคลิกเดียว
